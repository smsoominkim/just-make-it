[PRD] "일단만들어(Just Make It)" 커뮤니티 개발 명세서 (Replit Ver.)

1. 프로젝트 개요

프로젝트명: 일단만들어 (Just Make It)

성격: 태재 AI 바이브 코딩 아카데미 수강생 전용 폐쇄형 LMS 및 커뮤니티

핵심 가치: 복잡한 기능 없이 '수업 수강'과 '과제 공유'에만 집중하는 직관적인 UI

플랫폼: 웹 (Web) - PC/Mobile 반응형 지원

개발 환경: Replit (웹 브라우저 기반 IDE)

2. 사용자 대상 (Target User)

수강생 (Student):

이메일로 간편 가입/로그인

주차별 강의 영상 시청 및 자료 다운로드

과제 게시글 작성 (템플릿 기반) 및 타 수강생 과제 열람/댓글

관리자 (Admin):

주차별 콘텐츠(영상 링크, 자료 링크) 관리

회원 및 게시글 관리

4. 상세 기능 명세 (Functional Specs)

4.1. 회원가입 및 로그인 (Simple Auth)

진입점: 서비스 접속 시 비로그인 상태면 로그인 페이지로 리다이렉트 또는 GNB 로그인 버튼 노출.

기능:

이메일 회원가입: 이메일, 비밀번호, 닉네임(이름) 입력만으로 즉시 가입 완료 (이메일 인증 등 복잡한 절차 생략).

이메일 로그인: 이메일, 비밀번호로 로그인.

로그아웃: 세션 종료 및 홈으로 이동.

Replit 주의사항: 인증 정보는 LocalStorage나 쿠키에 안전하게 저장.

4.2. 아카데미 개요 (탭 0)

구성:

아카데미 소개 타이틀 및 설명 텍스트.

대표 이미지 배너.

데이터 연동: 관리자 페이지에서 입력한 '개요' 데이터 표시.

4.3. 주차별 학습 페이지 (탭 1~5 공통 구조)

스케치 화면을 반영하여 상하 2단 분리 구조를 채택합니다.

A. 상단: 학습 섹션 (Learning Area)

배경: 주목도를 높이기 위해 약한 회색 또는 브랜드 컬러 배경 적용 권장.

구성 요소:

주차 타이틀: (예: "1주차: AI-Native Creation")

강의 영상 (Embed): 유튜브 링크 임베드 플레이어 (반응형 16:9 비율).

수업 자료 버튼: [강의자료 다운로드] 버튼 (클릭 시 구글 드라이브 등 외부 링크로 새 창 열림).

진행률 (My Progress):

위치: 타이틀 옆 혹은 영상 하단.

표시: "나의 진행률 0%" 또는 "100% (완료)".

로직: 해당 주차 게시판에 본인이 쓴 글이 1개 이상 있으면 100%, 없으면 0%.

B. 하단: 과제 게시판 (Assignment Board)

섹션 타이틀: "수강생 과제"

글쓰기 버튼: 우측 상단 배치. 클릭 시 글쓰기 모달 또는 페이지 이동.

리스트 뷰:

형태: 카드형 그리드 (썸네일+제목+작성자) 또는 일반 게시판 리스트.

항목: 제목, 작성자(닉네임), 작성일.

상세 뷰 (게시글 클릭 시):

내용 표시 (마크다운 렌더링 지원).

댓글 영역: 댓글 작성 및 표시.

6. 기술 스택 및 개발 가이드 (Replit Optimized)

Replit 환경에서의 원활한 개발 및 배포를 위해 아래 스택을 권장합니다.

6.1 Frontend

React + Vite: (권장) Next.js보다 설정이 간편하고 Replit에서 빌드/구동 속도가 빠름.

Tailwind CSS: 스타일링을 위한 유틸리티 CSS.

React Router: SPA 페이지 이동 처리.

React-Markdown: 게시글 및 템플릿 렌더링용.

6.2 Backend & Database

Firebase (Authentication + Firestore):

이유: 서버 구축 없이 프론트엔드 코드만으로 로그인, DB, 호스팅까지 해결 가능.

설정: Firebase Console에서 프로젝트 생성 후 Config 값 가져오기.

Alternative (Supabase): SQL이 더 편하다면 Supabase 사용 가능.

6.3 Replit 환경 설정 (중요!)

Secret 관리:

Firebase API Key 등 민감 정보는 코드에 직접 적지 말고 Replit 좌측 하단 'Tools > Secrets' 에 저장할 것.

예: VITE_FIREBASE_API_KEY

포트 설정:

Vite 사용 시 vite.config.js에서 호스트를 0.0.0.0으로 설정해야 외부 접속이 원활함.

배포:

Replit 상단의 'Run' 버튼으로 개발 서버 확인.

상용 배포는 Replit Deploy 기능을 사용하거나 Vercel/Netlify에 Github 연동 배포 권장.
